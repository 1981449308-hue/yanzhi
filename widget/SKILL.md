# 小工具

## 要求
1. 单文件 HTML，样式、脚本全内联，双击就能开。
2. 移动端优先：视口 meta 必写，触控目标不小于 44px。
3. 不引外链资源，不请求网络。
4. 需要存状态就用 localStorage，键名带前缀。
5. 交付时说清三件事：存成什么文件名、怎么打开、怎么用。

## 风格
低饱和配色，宋体优先，留白多一些。
信息密度低，宁可少写功能。

## 禁止
不要做成需要安装的东西。
不要用构建工具。
不要交付半成品或带注释占位符的骨架。
